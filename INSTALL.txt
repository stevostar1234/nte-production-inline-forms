NTE forms for the client website

These files send to production Salesforce. They match the production client
forms at https://stevostar1234.github.io/nte-production-forms/ .
Stripe is live. Do not make test payments or submit fictional applications here.

1. Open the required .txt file in a plain-text editor and copy its entire contents.
2. In Squarespace, add a Code block, choose HTML and paste the code.
3. Keep Display Source switched off. Use one block per form.
4. Give the block the full available width and let its section grow to fit the
   form, including questions which appear after a selection.
5. Save and check the published page while logged out, on desktop and mobile.
   Also check it when reached through normal site navigation.

No separate CSS or JavaScript upload is needed. The website plan must permit
JavaScript in Code blocks. Images and fonts still need an internet connection;
logos use the production forms site and font files use Google's font hosting.
The secure logo upload uses the existing SharePoint link.

After submission, every form returns to https://www.nationaltransitionevent.com/.
The previous GitHub thank-you address also redirects there, including for older
installed blocks. Replace the two existing expression-of-interest blocks with
this release to allow ordinary website addresses such as www.example.com.

Update the exhibitor staff details, partner/sponsor staff details and guest
registration blocks to include the optional Armed Forces community headcount.
Delivery partners use the partner/sponsor staff details form.

Supporting pages contains the staff-form chooser and an optional thank-you
panel. Application/update links still use the production forms site until the
final client-hosted page URLs are supplied. Send Steven those URLs when ready.

TERMS AND PRIVACY
The application forms link to Kate's final NTE27 terms as separate PDF files.
Exhibitors use the exhibitor terms. Partner/sponsor and Delivery Partner
applications use the partner/sponsor terms. Privacy and terms each have their
own required checkbox and their own Salesforce field.

Replace any previously installed application block in full with this release.
The earlier unlinked testing checkboxes did not provide the final terms.
The PDFs are hosted alongside the production forms and do not count towards
Squarespace's code block size limit. All supplied blocks are below 400 KB and
300,000 characters. Send Steven the NTE-hosted PDF URLs if these are moved.

The package brochure link is ready and opens a temporary blank PDF. Steven can
replace it with the finished brochure, or point it to your hosted brochure,
without changing the form code. The finished brochure and final client-hosted
form URLs are still needed.
Internal NTE notifications go to nte@missioncommunity.org. The temporary finance
copy goes to Steven; the final accounts address will be configured separately.
